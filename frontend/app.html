About This System

The Travel Ambalangoda system bridges the information gap for tourists visiting the Ambalangoda region of Sri Lanka's Southern Province.

The Problem

Tourists visiting Ambalangoda face difficulties due to scattered, incomplete travel information — no single organized source exists for this region.

The Solution

A centralized web-based system providing categorized place details, transport info, entry fees, seasonal advice, and ready-made itineraries.

Technology Stack

Frontend: HTML5, CSS3, JavaScript
Backend: Laravel (PHP Framework)
Database: MySQL
Tools: VSCode, Git & GitHub
